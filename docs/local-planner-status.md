# 우사기 로컬 LLM 연결 작업 상태

작성: 2026-10-23. 현재 작업 트리 기준이며, 이번 변경은 아직 커밋하지 않았습니다.

## 반영한 코드

- `.env`의 `USE_LLM_PLANNER=true`일 때 실제 `bi:command` 대화 입력을 `chat-dialogue → QueryPlanner → LocalLlmClient`로 연결했습니다. 기존 Rasa는 플래그를 끄면 사용합니다.
- `LOCAL_LLM_MODEL_PATH`로 모델 경로를 읽고, 로컬 llama-server를 127.0.0.1:8080에서 실행합니다. 외부 API fallback은 없습니다.
- 실제 자연어 질문, 이전 대화 상태, 검증된 카탈로그 요약과 탐색 도구 정보를 모델에 제공합니다. 미리 작성한 응답으로 계획을 대체하지 않습니다.
- 지표/컬럼/대상/집계 탐색 도구를 Planner에 연결했습니다.
- 대상을 필수로 요구하지 않고, 구조화된 계획을 검증한 뒤 실행합니다.
- 비중 계산의 분자/분모에 등록 지표·필터·그룹을 지정할 수 있게 확장했습니다. 기본 분모는 같은 기간 전체 조직·브랜드·유무형입니다.
- 연도 조건 수정 시 다른 필드의 필터를 유지하도록 상태 처리를 변경했습니다.
- 원본 응답, 도구 탐색, 이전 상태, 계획, 검증, 실행 계획, 확인 질문, 최종 답변을 한 대화 기록에 저장합니다.
- 이 개발 경로의 실행기는 **가짜 데이터 전용**입니다. 결과에 실제 BI 실적이 아니라는 표시를 넣습니다. 기존 검색 입력의 BI 경로는 별도로 남아 있습니다.
- LLM 모드에서는 Rasa 자동 재학습을 시작하지 않습니다. 모델 동시 구동에 따른 메모리 경합을 줄이기 위한 분리입니다.

## 확인한 사실과 한계

- 실제 Qwen3 1.7B GGUF가 로컬에서 실행되었고, 단순 JSON 응답과 health check가 성공했습니다.
- 코드 단계의 기존/추가 테스트 16개는 실행 당시 통과했습니다. 이를 실제 자연어 대화 정확도로 해석하면 안 됩니다.
- 실제 모델의 연속 대화 확인을 시도했으나, `레이델 26년 가중분 알려줘`에도 불필요한 확인 질문이나 잘못된 계획이 나오는 사례가 있었습니다. **사용자가 요구한 연속 대화 완료 기준은 충족했다고 볼 수 없습니다.**
- 프롬프트와 입력 컨텍스트 구성을 조정했지만 실제 모델 해석 품질은 아직 보장하지 못합니다. 모델 연결과 실행기 코드의 존재를 대화 품질 완료와 혼동하지 마세요.
- `주문금액`은 현재 카탈로그에 승인된 지표 매핑이 없습니다. 주문량/예상취급액으로 임의 대체하지 않습니다.
- 실제 BI 로그인이나 조회는 수행하지 않았습니다. 모델 다운로드도 수행하지 않았습니다.
- 사용자가 추가 실행을 중단하라고 요청하여 모델 검증 프로세스와 그 소유 llama-server를 종료했습니다. 이후 앱 재시작이나 추가 모델 테스트를 하지 않았습니다.

## GPT 검토 시 요청

`docs/local-planner.md`, `src/planner/`, `src/power-bi.js`, `src/commands/handlers.js`, `src/main.js`부터 확인하세요. 기존 Rasa 설계 문서와 현재 LLM 개발 경로를 구분하세요.

검토할 핵심은 실제 채팅 경로의 연결, 작은 로컬 모델에 주는 문맥과 구조화 출력 방식, 상태 수정의 일관성, 분자/분모 계산의 의미, 검증과 오류 처리입니다. 문장별 JS 규칙을 늘리거나 가짜 응답을 실제 모델 해석으로 제시하지 않는 방향으로 검토하세요.

패키지는 코드 검토용입니다. 모델 가중치, 실행기 바이너리, node_modules, Python 가상환경, 인증 캐시, 로컬 `.env`는 제외했습니다. `.env.example`에는 설정 항목만 있습니다. 로컬 대화·BI 메타데이터와 중간 검증 기록은 검토 자료로 포함될 수 있습니다.
