# 우사기 커스텀 Planner 학습자료 정리

원본 34건. 학습 초안 9건, 평가 초안 5건. 실제 모델 학습·다운로드·BI 조회는 실행하지 않았다.

## 사용자 확인 정의

문화팀 = 문화서비스팀(문화서비스). 분당 취급고 = 전체 예상취급액 합계 / 가중분 합계. 분당 이익액 = 전체 한계이익 합계 / 가중분 합계. 비율은 행별 평균이 아니다. 브랜드 편성비중은 같은 기간 전체 조직·전체 브랜드 가중분 대비다. 새 비율과 브랜드 비중은 현재 실행 지표 등록·범위 확장이 필요해 복합 질문을 SFT에서 보류한다.

## 반드시 피할 과거 오류

- 긴 설명문을 BI 질문으로 오인해 숫자를 반환한 success 기록은 학습 제외.
- 문화팀을 편성팀으로 선택하고 0%를 답한 기록은 정답이 아니다.
- 브랜드 전체 요청을 개별 상품 하나 선택으로 바꾸지 않는다.
- 왜 편성팀을 찾았냐는 말은 조직 정정이며 원인 분석 거절 대상이 아니다.
- 엇그제/여덟시/26년 같은 표현을 이해하고 필요한 시간 구분만 확인한다.

## 파일과 사용 범위

`data/training/annotations.json`: 원본 전체의 출처 ID·원문·의도·보류 근거. 새 대화 목록이 아니라 원본에서 파생한 학습 주석이다.
`decisions.json`: 이번 사용자 확인과 미확인 업무 정의.
`train.planner.jsonl` / `eval.planner.jsonl`: messages 형식의 계획 생성용 초안. 학습 도구에 맞는 포맷 변환은 모델 선택 후 수행한다.
`manifest.json`: 원본 해시, 분할 기준, 개수.

표본 수가 적고 표현·업무 범위가 좁아 커스텀 모델 성능을 보장하지 않는다. 이 초안의 평가군은 이번에 처음 정한 분할이며, 과거 개발 중 이미 본 대화여서 완전한 독립 평가로 볼 수 없다. 새 사용자 질문으로 별도 회귀 평가를 더 모아야 한다. 기존 잘못된 봇 답변과 실제 BI 수치는 messages 정답에 넣지 않는다. 합성 데이터·이전 데모는 섞지 않았다.

현재 실행 모델을 바꾸거나 중단했던 LLM 연결 작업을 재개하지 않는다. 모델 종류·학습 자원·추가 데이터가 준비된 뒤 실제 학습을 별도 진행한다.
